Manual Installation

1 Download theme and random text phrases 
curl -fsSL https://raw.githubusercontent.com/codershubinc/naty-zsh/main/naty-zsh.zsh-theme -o ${ZSH_CUSTOM:-$HOME/.oh-my-zsh/custom}/themes/naty-zsh.zsh-theme
curl -fsSL https://raw.githubusercontent.com/codershubinc/naty-zsh/main/naty-zsh-random-texts.txt -o ${ZSH_CUSTOM:-$HOME/.oh-my-zsh/custom}/themes/naty-zsh-random-texts.txt
2 Set theme in ~/.zshrc 
ZSH_THEME="naty-zsh"
3 Reload your shell 
source ~/.zshrc
1 Create theme directory & download files 
mkdir -p ~/.zsh/themes/naty-zsh
curl -fsSL https://raw.githubusercontent.com/codershubinc/naty-zsh/main/naty-zsh.zsh-theme -o ~/.zsh/themes/naty-zsh/naty-zsh.zsh-theme
curl -fsSL https://raw.githubusercontent.com/codershubinc/naty-zsh/main/naty-zsh-random-texts.txt -o ~/.zsh/themes/naty-zsh/naty-zsh-random-texts.txt
2 Source theme in ~/.zshrc 
echo "source ~/.zsh/themes/naty-zsh/naty-zsh.zsh-theme" >> ~/.zshrc
3 Reload your shell 
source ~/.zshrc
💡 Standalone & Oh My Zsh Ready: naty-zsh has zero external framework dependencies and runs directly in pure Zsh as well as Oh My Zsh.

💡 Note on Icons: naty-zsh uses Nerd Fonts for terminal glyphs (Arch, Git branch, folder, and runtime badges). Be sure your terminal emulator (Alacritty, Kitty, WezTerm, iTerm2, etc.) is configured with any Nerd Font (e.g. JetBrains Mono Nerd Font, FiraCode Nerd Font).
